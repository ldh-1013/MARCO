# 마르코! — 프로토타입 전체 구현 프롬프트

> **프로토타입의 목적**: "이 게임이 정말 재미있는가? 돈 주고 살 가치가 있는가?"를 확인한다.
> 따라서 **핵심 루프의 모든 고리가 빠짐없이 있어야 한다.** 고리 하나가 없으면 딱 그 지점에서 재미가 끊기고, 그러면 답을 얻을 수 없다.

---

## 0. 검증해야 할 루프 — 이게 전부 돌아가야 한다

```
말한다 → 음성 3등급 분류 → 파문 발생 → 재질·차폐 적용 → 시야가 밝아진다
   → 잔상이 남는다 → 술래가 방향을 안다 → 추격 → 태그
   → 메아리 전환 → 소나로 관전 → 노크로 유인
   → 밸브를 연다 → 역류와 싸운다 → 게이트가 열린다 → 탈출
   → 결과 화면 → 어워드 → "한 판 더"
```

## 8. 프로토타입이 답해야 할 질문

구현이 끝나면 3~4인으로 플레이하고 기록한다. **이게 프로토타입의 존재 이유다.**

### 1순위 — 이게 안 되면 설계를 다시 본다

| # | 질문 |
|---|---|
| 1 | **"말해야 보인다"는 딜레마가 실제로 긴장을 만드는가** — 말하기를 망설이는 순간이 나오는가 |
| 2 | **술래가 밸브 하나를 계속 지키는 것이 최적해가 아닌가** — v0.3 변경 전체의 목적 |
| 3 | **"한 판 더 하자"가 나오는가** — 최종 기준 |

### 2순위 — 수치 조정으로 해결되는 것

| # | 질문 | 벗어나면 |
|---|---|---|
| 4 | 술래 승률 40~60%인가 | §9.4 순서(①이속 ②회전시간 ③역류)로 조정 |
| 5 | 역류 150초가 압박으로 느껴지는가 | 빡빡하면 210초, 느슨하면 120초 |
| 6 | 60초 이상 무사건 구간이 없는가 | §20.3 합격 기준 |
| 7 | 종료가 아슬아슬한가 | 종반 압박이 작동하는가 |
| 8 | 메아리가 지루하지 않은가 | 소나 8개 상한, 노크 5회 조정 |
| 9 | 무마이크로도 최소한 참여되는가 | 찰칵이 리스폰 120초 조정 |

**1~3번이 "구매할 가치가 있는가"에 직접 답한다.** 나머지는 그 답이 "그렇다"일 때 다듬는 것이다.

## 9. 멈춰야 하는 지점

| 상황 | 조치 |
|---|---|
| 배치 검증 10쌍이 조정해도 합격 안 됨 | **멈추고 보고.** 구역 배치를 다시 계산해야 한다 |
| 기획서 수치와 기존 코드가 충돌 | **멈추고 보고.** 임의로 고르지 마라 |
| 기획서에 정의가 없는 지점 발견 | **GAP으로 기록하고 보고.** 값을 창작하지 마라 |
| 탈출자 관전 규칙 | 미정 항목. 프로토타입은 "탈출 = 관전만, 노크 불가"로 임시 처리하고 GAP 유지 |
| 스태미나 회복 규칙 / 페널티 중첩 | 기획서에 없을 가능성이 높다. GAP으로 올리고 임시값 명시 |
| 호흡음의 무성 생존상 집계 여부 | 기획서 미명시. GAP |

**GAP이 쌓이는 것은 정상이다.** 창작한 값을 확정처럼 적는 것이 사고다.
